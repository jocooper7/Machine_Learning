## Summary
This course covers the training and implementation of traditional AI models, implementation of Multilayer Perceptron, and training and tuning of these models. Also included is data preprocessing, leaning, and imputation.

## Final Project
This project involves the creation of a k-nearest neighbors classification algorithm and a Multilayer Perceptron Classifier. The first step of the project was to analyze the initial dataset to find the most appropriate model for the dataset. This was followed by creation, training, and tuning of this KNN model. This was followed by the implementation, training, and tuning of the MLP Classifier for the Scikit-Learn load_digits dataset. Both models were tuned with GridSearchCV for finding an acceptable set of hyperparamters. Accuracy metrics from before and after tuning are compared to analyze the effectiveness of the tuning methods.
